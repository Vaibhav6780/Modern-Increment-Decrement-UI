# Aesthetic Counter UI

A Simple and beautiful, minimal, and responsive counter app built using **HTML**, **CSS**, and **JavaScript**. This project demonstrates visual hierarchy, modern design practices, and user interaction with a simple increment/decrement counter interface.

![image](https://github.com/user-attachments/assets/8dee3153-fc67-42c7-bdc5-deb8a327e6fc)


## 🚀 Features

- Smooth color gradient background
- Clean and modern UI design
- Responsive layout using Flexbox
- Interactive buttons with hover animation
- Easy-to-read number display

## 🔧 Tech Stack

- HTML5
- CSS3 (Flexbox, Gradients, Transitions)
- Vanilla JavaScript (DOM Manipulation)
